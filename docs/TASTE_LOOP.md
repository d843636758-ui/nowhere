# 品味回路 (Taste Loop)

> 杆不是文档写死的,是你读出来的。
> 把"你骂一句我修一批"变成制度。

---

## 循环流程

```
抽样 → 旋复盲评 → 回填 golden set → 裁判越判越像你
```

### 1. 抽样

```bash
cd C:\Users\84989\Desktop\nowhere_repo
python nowhere/tests/qa_taste_sample.py
python nowhere/tests/qa_taste_sample.py --seed 42    # 可复现
python nowhere/tests/qa_taste_sample.py --count 20   # 抽更多
```

脚本做的事:
- 用真实渲染管线(open_door + walk)跑出文本
- 拆段、去地名、打乱顺序
- 保存到 `docs/taste_samples/YYYY-MM-DD.md`
- 每段带种子号,可复现

### 2. 旋复盲评

打开生成的 md 文件,每段评一个字:

| 评语 | 含义 |
|------|------|
| **好** | 放进游戏不丢人,有血肉,声口对 |
| **平** | 能用但没劲,像资料卡,模板壳 |
| **差** | 断气/错配/空泛/编造/禁词 |

愿意多写几句更好,但一个字也够用。

### 3. 回填 golden set

评完的段回填到 `nowhere/tests/qa_lqa_golden.json`:

**好段** → 作为 PASS 好样例:
```json
{"id": "G21", "label": "PASS", "env": {}, "text": "你评的好段原文", "note": "旋复: 好。盲评日期 2026-08-20"}
```

**平段** → 视问题定 S 级:
- 信息对但平 → S4 (疲劳)
- 模板壳 → S3 (断气)
- 其他对号入座

```json
{"id": "G22", "label": "S4", "env": {}, "text": "你评的平段原文", "note": "旋复: 平。模板壳。盲评日期 2026-08-20"}
```

**差段** → 按严重度分:
- S1: 事实错/破沉浸
- S2: 错配(气候/物种/风俗/文化区)
- S3: 断气(拼段/禁词/人称漂移)
- S4: 疲劳(复读/死寂)

```json
{"id": "G23", "label": "S3", "env": {}, "text": "你评的差段原文", "note": "旋复: 差。缺句号拼接。盲评日期 2026-08-20"}
```

**回填规则**:
- 追加到 `qa_lqa_golden.json` 数组末尾
- id 从 G21 开始顺序编号(现有 20 条 G01-G20)
- env 字段: 能填就填(温度/biome/时段/纬度),填不了就留空 `{}`
- note 字段必填,写清评语和日期

### 4. 裁判校准

回填后的 golden set 用于卡24 的 LLM 裁判校验:
- 裁判先用 golden set 跑,一致率 ≥80% 才上岗
- golden 越大、越准,裁判越像旋复
- **裁判 ≠ 生成方**(生成是模板+手写卡,裁判是另一个 LLM)

---

## 节奏

**每波大改后跑一次**。触发时机:
- 卡32(级差抽卡)、卡33(场景池 biome 门禁)、卡35(缝合工坊)等质量卡合入后
- 大批量手写卡(卡30 加城市流水线)跑完后
- 旋复觉得"最近写的不对味"时

不需要每天跑。一次抽 10-20 段,评完回填,半小时以内。

---

## 铁律

1. **产物只进 golden set,不直接改卡。** 改卡走卡34(全卡打分普查)的优先清单。
2. **盲评是真的盲。** 抽样脚本已去地名,评审者不应手动查种子还原地点。
3. **裁判不许当裁判又当球员。** 裁判模型 ≠ 文本生成方。
4. **golden set 只增不删。** 旧好样例永远留着,新评的追加。除非样例本身有事实错误(比如 env 填错了),才修正。

## 与卡24(语义文本审计)的关系

| | 卡24: qa_lqa | 卡36: taste loop |
|---|---|---|
| 方法 | 规则层全量 + LLM 裁判抽样 | 人工盲评 |
| 对象 | 渲染管线实时输出 | 渲染管线实时输出 |
| 产物 | qa_lqa_report.md (bug 清单) | golden set 增长 (裁判校准) |
| 频率 | 每波大改后 | 每波大改后 |
| 成本 | 自动化 | 旋复人工 30 分钟 |

两者互补: 卡24 找 bug,taste loop 建品味基准。golden set 是卡24 裁判层的地基。
