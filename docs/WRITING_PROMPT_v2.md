# 第一节：质量地板（v1 原文照搬，零改动）

## 旧北京声口五条铁律

1. **一开场就在现场**。不许"我来到了"、"走进去一看"——直接给画面。
2. **你全程在动**。蹲、翻、摸、闻、嚼——身体在场，不是站在远处看。
3. **声音是惊喜**。不预告，不总结——声音来了，你听到了。
4. **色香味叠层次**。颜色、气味、触感、温度——至少两层，不是"很好吃"。
5. **零攻略百科腔**。不许"始建于XX年"、"是XX的象征"、"被誉为XX"——给体感，不给评价。

## 禁词表

绝对禁止出现在卡文案中的词：

**空泛程度词**：很、非常、十分、巨大、美丽

**空泛模糊词**：一些、很多、感觉、仿佛、好像、似乎、有点

违反任何一条 = 废卡。

## 时间季节双硬要求

- **hours**：必须是整数，格式 `[起, 止)`，左闭右开。`[6, 8]` = 6点到8点。
- **months**：季节限定卡必须写。`[6, 7, 8]` = 只在6/7/8月出现。不写 = 全年有效。
- **跨午夜**：不要写 `[22, 1]`（代码不会命中），改用 `[22, 24]`。

## 四维度内容要求

每张方志卡至少覆盖两个维度：

1. **动物**：当地能见到的动物——鸟、鱼、虫、家畜。不是动物园里的，是街上/河里/天上碰见的。
2. **水文**：河、湖、海、泉、雨、雪、雾——水在当地的样子。
3. **植物**：树、花、草、果——当地长什么。季节限定的植物尤其好（樱花、红叶、杏花）。
4. **天空**：云、星、月、日出日落、极光、白夜——抬头看到的。

## 质量地板样例

以下三张卡是经过敦煌单测验证的合格卡。新卡的质量不得低于这些样例。

### 廷巴克图

> 你蹲在泥墙根下，土是晒透了的黄，手一摸掉渣。骆驼从身边过，蹄子踩在沙上闷响，驼峰上的盐袋晃着。风从撒哈拉那边来，热的，带着干草和牲口味。远处宣礼塔的方向有人在喊，声音被风撕成一条一条的。

### 阿瑜陀耶

> 佛塔的砖被树根包住了，根须从砖缝里钻出来，像手指。你把手掌贴上去，砖面粗粝，有太阳的余温。河对岸有人在烧甘蔗叶，白烟低低地飘过来，呛鼻。一辆拖拉机突突突地从土路上过去，扬起的灰半天不落。

### 敦煌

**物产**：
> 你蹲在鸣沙山背风的一面,捧起一把沙,细得像磨过的面,金黄,从指缝里漏下去,一声不响。沙是干透了的,干到攥不成团;表层晒了一整天,烫手,你往深里一翻,底下那层是凉的。整座沙丘就是由这样的沙堆成的,风一过,千万粒沙互相蹭着,发出嗡嗡的响,像整座山在轻轻打鼾。

**声音**：
> 你从沙丘顶往下滑,先是一声闷响,接着整面坡活过来,嗡嗡的,像有人在一张巨大的鼓皮上慢慢拉弓。风再大些,那声音变了调,呜呜的,又细又长;你停下,它也跟着停,你一动,它又贴上来。

**痕迹**：
> 你站在玉门关前,一座土黄色的方城立在戈壁滩上,四壁让风啃得棱角全无,像一块忘了收回去的泥坯。墙根下,风把沙堆成一道一道波纹,你伸手摸墙,夯土酥得掉渣,指头上沾了黄。

**美食**：
> 一盘驴肉黄面端上来,面黄澄澄的,浇头是驴肉丁和豆腐丁炒的臊子,油亮。你拿筷子拌开,醋和油泼辣子一搅,热气和辣香一起冲起来,鼻子里先酸后辣。

**节律**：
> 天没亮,沙漠是冷的,你裹紧外套,脚底下的沙还带着夜里的凉。太阳从沙丘的棱线上冒出来,光先点着最高的那座沙山,再一层一层漫过来,整片鸣沙山从灰蓝变成金黄。

# 第二节：加厚专用条款

加厚不是"重写一个地方"，是"往一个已经不错的地方添卡"。难度更高——添的卡不许和已有卡撞角。

## 2.1 开工前先读已有卡

写新卡之前，必须做这一步：

1. 打开 `localcolor.json`（含区域文件），找到该地的全部已有卡。
2. 列一张"已写过的角度"清单。每张已有卡用一句话总结它从什么角度切入。
3. 新卡逐条避开这张清单。

**示例**：喀什已有卡——
- 物产/0：老茶馆的茶碗（物件，静态）
- 声音/0：巴扎的吆喝（声音，人群）
- 痕迹/0：艾提尕尔广场的翻新（痕迹，建筑）
- 美食/0：烤包子（食物，动作）

新卡就不许再从"茶碗""巴扎吆喝""广场翻新""烤包子"进。可以写"铜匠敲铜壶的声音""巷子里晾着的花毯""馕坑边的面粉味"。

## 2.2 新卡切入角清单

每地新卡至少用到以下 6 种角中的 4 种（同地不同卡之间轮换）：

| 角 | 说明 | 好例子 | 坏例子（俗角） |
|---|---|---|---|
| 一个时刻 | 不是清晨/黄昏这两个俗角 | "下午四点下学时""打烊前半小时""邮局关门前十分钟" | "清晨的巴扎""黄昏的河边" |
| 一种天气 | 雨里/起风时/大雾天/暴晒时 | "雨后的石板路反光""起风时晾着的布全朝一个方向" | "阳光明媚的日子" |
| 一类人 | 摆摊的/赶路的/守夜的/放学的 | "卖石榴汁的老头,手摇榨汁机吱嘎响""守夜人拿手电扫了一圈" | "人们""游客""当地人" |
| 一件小事 | 称重/找零/卷帘门/系鞋带 | "她把秤砣拨到三两,又加了一颗""卷帘门拉到一半卡住了" | "商贩在做生意" |
| 一样声音 | 一种鸟/一种机器/一种水声 | "缝纫机嗒嗒嗒,从二楼窗户漏出来""鸽哨在头顶绕了一圈" | "热闹的声音""嘈杂的市集" |
| 身体的一个部位 | 脚底/后颈/指腹/舌尖 | "后颈晒得发烫""脚底的石子硌得你换了个走法""指尖摸到墙皮脱落的地方" | "你感到很舒服" |

**铁律：每张卡必须钉死在一个具体瞬间。** 一旦开始总结（"喀什是丝绸之路的重镇"），就写不出第二张不同的卡了。总结式写法是同地异卡的最大敌人。

## 2.3 已有卡角度冲突判定

新卡写完后，和"已写过的角度"清单逐条比对：

- 如果新卡的核心意象和某张已有卡重合（哪怕措辞不同），废掉重写。
- 判定标准不是"字面不重复"，而是"画面不重复"。"茶碗在手里转"和"茶杯搁在桌上凉了"是同一个画面（茶具+静态），算撞。

# 第三节：节律卡专节

节律卡是这次加厚的主攻维度。从 13 地扩展到 80 地。

## 3.1 格式

```json
{
  "hours": [起, 止),
  "text": "具体场景描写",
  "months": [月, 月, ...]
}
```

- `hours`：左闭右开，整数。`[6, 8]` = 6:00-7:59 有效。
- `text`：2-3 句散文，声口照第一节铁律。
- `months`：可选。不写 = 全年有效。写了 = 只在这些月份出现。

## 3.2 节律卡怎么写

节律卡不是"晚上的城市很热闹"，是：

> 二十二点的巴扎，收摊的人把毯子卷起来，卷到最后一张，扬出一片灰，灯一盏一盏灭。

节律卡必须钉死在一个具体的小时刻度上。写出"那个时间点在发生什么具体的事"。

**好的节律卡**：
- `[5, 7]`：天没亮，沙漠是冷的，你裹紧外套，脚底下的沙还带着夜里的凉。
- `[22, 24]`：末班车之前，居酒屋开始往外吐人。
- `[13, 15]`：正午，地皮烫得站不住。你踩着影子的边缘走，影子只有脚底下一点点。

**坏的节律卡**：
- "晚上的城市灯火通明"（没有具体时刻，没有具体动作）
- "清晨，万物苏醒"（俗角+总结式）

## 3.3 months 季节限定是硬货

有季节现象的地，months 卡是必写的。以下现象必须对应 months：

| 现象 | months 示例 | 说明 |
|---|---|---|
| 极光 | `[9, 10, 11, 12, 1, 2, 3]` | 高纬度冬季 |
| 白夜/极昼 | `[6, 7]` | 夏季高纬度 |
| 雨季 | 查该地真实气候 | 热带/季风区 |
| 旱季 | 查该地真实气候 | 热带/季风区 |
| 渔汛 | 查该地真实渔业数据 | 沿海/河流 |
| 花期 | 查该地真实花期 | 樱花/杏花/薰衣草等 |
| 雪季 | 查该地真实降雪月份 | 高纬/高海拔 |
| 节庆前夜 | 查该地真实节日日期 | 用 zim 实据 |

**写前必须查该地真实气候数据**（zim 实据 / 气候常识），不许凭感觉写。冰岛极光写 `[6, 7, 8]` = 废卡（夏天没有极光）。

## 3.4 南半球翻转提醒

南半球的季节和北半球相反：

- 悉尼 12 月是夏天，不是冬天。圣诞卡写"雪" = 错配。
- 布宜诺斯艾利斯 7 月是冬天，不是夏天。
- 开普敦 6-8 月是雨季，不是旱季。

写南半球的 months 卡时，先确认该地的真实季节，再写 months。

## 3.5 节律卡的时间覆盖

每地的节律卡尽量覆盖不同时段，避免全堆在清晨和深夜：

- 优先补深夜档 `[22, 24]`（现在全球深夜卡最薄）
- 其次补午后档 `[13, 16]`（被忽略的时段）
- 最后补凌晨档 `[0, 5]`（特殊场景才写）

# 第四节：防模板回潮条款

量产到第 8 批时最容易犯的错：句式开始重复，比喻开始偷懒。

## 4.1 比喻只许在示范里出现

质量地板里的好比喻（"空气厚得像布""沙细得像磨过的面"），只许在示范里出现，不许被抄进新卡。

比喻要为当下的卡现造。每张卡的比喻必须是这张卡独有的。

## 4.2 每 25 张回头读

每写 25 张卡，回头读自己第 1 批写的 5 张：

- 句式结构撞了就停，换角。
- 如果发现自己在用同样的句式开头（"你蹲在……""你站在……"），换动词。
- 如果三张卡的节奏都是"场景→声音→收束"，换结构。

## 4.3 量词滥用监控

禁词表之外，增加三个高频量词的监控：

- **一次**：连续 5 张都用"一次"开头就该警觉。
- **一阵**：连续 5 张都用"一阵"开头就该警觉。
- **一片**：连续 5 张都用"一片"开头就该警觉。

这不是禁词（可以用），但连续使用说明思路枯竭。

## 4.4 句式多样性自检

写完一批后，抽查 10 张卡的首句：

- 首句动词不能重复超过 2 次（"你蹲在""你蹲在""你蹲在" = 模板化）。
- 首句不能全是"你+动词"开头（偶尔可以用"风从……""灯亮了……"等非"你"开头）。
- 每张卡的节奏不能和前一张完全一致。

# 第五节：自查清单升级

写完每地必跑以下清单。有一条不过 = 废卡，不许交差。

## 5.1 禁词扫描

- [ ] 无"很/非常/十分/巨大/美丽"

- [ ] R1-R6 评分 ≥ 4（如果走 LLM 裁判路径）
- [ ] hours 是整数
- [ ] hours 格式 `[起, 止)`，左闭右开
- [ ] hours 范围 0-24
- [ ] 无 `[22, 1]` 式跨午夜（改用 `[22, 24]`）
- [ ] months 该带的带了（季节限定卡必须写 months）

## 5.3 角度不撞

- [ ] 新卡与已有卡的角度清单逐条比对，无撞角
- [ ] 新卡的核心意象不与已有卡重合
- [ ] 同地不同卡之间至少用到 4 种不同切入角

## 5.4 四维度可见

- [ ] 每张卡至少覆盖 2 个维度（动物/水文/植物/天空）
- [ ] 无"总结式写法"（"XX是丝绸之路的重镇"类）

## 5.5 声口检查

- [ ] 一开场就在现场（无"我来到了""走进去一看"）
- [ ] 你全程在动（有身体动作）
- [ ] 声音不预告不总结
- [ ] 零攻略百科腔（无"始建于XX年""是XX的象征"）
- [ ] 人称统一（"你"）

## 5.6 节律卡专项

- [ ] 节律卡钉死在一个具体时刻（不是"晚上""清晨"这种模糊时段）
- [ ] months 卡的 months 值与真实气候一致
- [ ] 南半球季节已翻转确认
- [ ] 节律卡覆盖不同时段（不全堆在清晨和深夜）
